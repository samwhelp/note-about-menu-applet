## Usage


### default

run

``` sh
./style-select.sh
```

or run

``` sh
THE_MASTER_MENU_FACTORY=fzf THE_MASTER_DE=gnome ./style-select.sh
```




### alternative

run

``` sh
THE_MASTER_MENU_FACTORY=rofi THE_MASTER_DE=xfce ./style-select.sh
```
