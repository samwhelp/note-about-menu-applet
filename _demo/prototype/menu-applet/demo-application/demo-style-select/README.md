## Usage


### default

run

``` sh
./style-select.sh
```

or run

``` sh
THE_DEFAULT_MENU_FACTORY=fzf THE_DEFAULT_DE=gnome ./style-select.sh
```




### alternative

run

``` sh
THE_DEFAULT_MENU_FACTORY=rofi THE_DEFAULT_DE=xfce ./style-select.sh
```
